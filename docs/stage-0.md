## 3. Розпізнавання і переклад (`prototypes/speech`)

60 речень FLEURS (одні й ті самі речення українською та англійською), середня довжина запису 10,2 с (uk) і 9,4 с (en). Модель завантажена заздалегідь. Затримка: від готового запису до готового тексту, без затримки звукового тракту й малювання. chrF: схожість із перекладом людини, більше означає краще. Opus-MT рахувався на процесорі (int8).

### Пауза UA→EN

| Варіант | p50 | p95 | chrF | Відеопам'ять |
| --- | --- | --- | --- | --- |
| large-v3, translate | 490 мс | 764 мс | 56,7 | ~3,6 ГБ |
| large-v3 q5_0, translate | 487 мс | 768 мс | 56,5 | ~1,7 ГБ |
| turbo + opus-mt-uk-en | 386 мс | 549 мс | 55,0 | ~1,9 ГБ |
| **turbo + opus-mt-tc-big-zle-en** | **471 мс** | **702 мс** | **61,8** | ~1,9 ГБ |
| turbo, translate | 279 мс | 377 мс | 0,4 | непридатно: сміття на виході |

На фразах по 3 с (обрізані записи, лише швидкість): turbo + tc-big дає p50 282 мс, p95 329 мс. Ціль 0,5–1 с виконується.

### Субтитри EN→UA

| Варіант | p50 | p95 | chrF |
| --- | --- | --- | --- |
| turbo, лише англійський текст | 223 мс | 258 мс | 93,8 (до англійського тексту) |
| turbo + opus-mt-en-uk | 309 мс | 402 мс | 48,8 |
| **turbo + opus-mt-tc-big-en-zle** | **444 мс** | **609 мс** | **59,6** |

До цього додається очікування кінця фрази. Часткові («сірі») субтитри в реальному часі не виміряні (⏳).

### Один спільний Whisper

Працює: пауза (лише розпізнавання, 3 с) 206 мс на вільному GPU і 430 мс (p95 494 мс), коли субтитри йдуть без перерви. З перекладом це приблизно 0,5 с, тобто в межах цілі. У застосунку паузі варто дати пріоритет у черзі.

### Silero VAD

Потрібен. Без нього на тиші й шумі Whisper вигадує «Дякую за перегляд!», «Дякую.», «you». З ним на всіх 4 зразках тиші й шуму порожньо, а на справжній мові якість майже та сама (chrF 92,8 проти 93,8). Ціна близько 30 мс.

### Що не спрацювало

`audio_ctx` (скорочене вікно кодувальника заради швидкості) ламає розпізнавання: chrF 92,6 → 45,2 для української, p95 до 3,5 с. Не використовувати.

## Пропозиція щодо моделей

Один **large-v3-turbo** для всього, переклад через **Opus-MT tc-big** (`zle-en` для паузи, `en-zle` з `>>ukr<<` для субтитрів), Silero VAD перед Whisper. Базові Opus-MT з плану швидші на ~85–135 мс, але помітно гірші. Окремий large-v3 не потрібен.

Обмеження вимірів: FLEURS це читані речення, а не жива розмова з акцентами й поганим мікрофоном; 60 речень; вимір ішов через `whisper-server` (готова збірка whisper.cpp) і Python. **`whisper-rs` + CUDA та `ct2rs` у Rust ще не збиралися**: для цього потрібні CUDA Toolkit і libclang, яких на машині немає.

## Що треба зробити руками

1. **Вікно в дзвінках.** `cargo run -p overlay`, далі в Zoom, Teams, Meet і Slack демонструвати весь екран, попросити іншу людину (або другий пристрій) підтвердити, що вікна не видно. Заодно натиснути Ctrl+Alt+Space, перетягнути вікно, перезапустити.
2. **VB-Cable.** Встановити з https://vb-audio.com/Cable/ (драйвер, потрібні права адміністратора і перезавантаження). Далі `cargo run -p mic-gate -- run --out "CABLE Input" --in "Микрофон"`, у програмі для дзвінків вибрати мікрофон «CABLE Output», тримати F8.
3. **CUDA Toolkit і LLVM** (кілька ГБ, права адміністратора), щоб перевірити збірку `whisper-rs` і `ct2rs`.
