# Sidekick: матеріали планування

Робочий асистент для Windows на Rust. Стан на 26.11.2026: етап 0 виміряно (див. [stage-0.md](stage-0.md)), етап 1a зроблено (застосунок у `app/`), з етапу 1b готові субтитри EN→UA. Режим паузи ще не почато. Лишилися ручні перевірки в програмах для дзвінків.

## Як запустити

```
cd app && cargo run                 # задачі, звіт, вікно
bash app/speech/build.sh            # процес розпізнавання для мітингів (потрібні CUDA 12.9, LLVM, CMake)
bash app/speech/build.sh test       # його тести
```

Розпізнавання працює окремим процесом `sidekick-speech.exe`: застосунок збирається без CUDA, падіння розпізнавання не зачіпає задачі, а відеопам'ять (~2,3 ГБ) звільняється, щойно мітинг закінчено. `build.sh` кладе його поруч з `sidekick.exe`.

Моделі для мітингу (`ggml-large-v3-turbo.bin`, `ggml-silero-v6.2.0.bin`, папка `opus-mt-tc-big-en-zle`) шукаються в папці з налаштувань, потім у `SIDEKICK_MODELS`, потім у `%APPDATA%\dev.sidekick.app\models`. На цій машині вони вже лежать у `prototypes/speech/models`. Журнал розпізнавання: `speech.log` у папці даних.

Субтитри на записах FLEURS: остаточний рядок з'являється приблизно через 1 с після кінця фрази (0,6 с очікування тиші, ~0,2 с розпізнавання, ~0,1 с перекладу), сірий попередній рядок оновлюється щосекунди. Фраза довша за 12 с ріжеться в найтихішому місці.
