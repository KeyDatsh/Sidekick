# Персональный ассистент для Windows: список идей

Этап: сбор идей (реализация позже).

## 1. Задачник
Место, куда я кидаю задачи и планирую их выполнение.
- Поля задачи: **заголовок**, **текст**, **кому** (исполнитель).
- Планирование выполнения (уточнить: дата/срок? статус?).

## Оновлення 2026-11-25 (нові вимоги)

### 0. Платформа і загальне
- **ОС:** Windows.
- **Мова:** Rust.
- Призначення: помічник у роботі (задачі + мітинги).

### 1а. Задачник: доповнення
- Швидко кидати таски/задачі.
- **Розподіл по днях** і легке перенесення задач між днями.
- **Звіт у кінці дня** (що зроблено, що перенесено).

### 2. Вікно-оверлей
- Маленьке вікно, приблизно **1/8 екрана**.
- **Позицію задає користувач** (перетягнути куди зручно, запам'ятовується).
- **Стиль:** темна тема в стилі Windows 11 (Fluent, темний напівпрозорий фон з ефектом Mica/Acrylic).
- **Неактивний стан:** напівпрозорий, завжди видимий поверх інших вікон на своєму місці, **click-through** (мишка проходить крізь вікно, інші програми він не блокує).
- **Активний стан:** вмикається **гарячою клавішею, яку я сам задаю в налаштуваннях**.
- **Ніколи не показується при демонстрації екрана**: обов'язково, в усіх програмах (Zoom, Teams, Meet, Slack, OBS тощо). Технічно це `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`, працює на Windows 10 2004 і новіших.

### 3. Режим «помічник на мітингах»
- **Онлайн-переклад EN→UA** мови співрозмовників у вигляді субтитрів у вікні.
- **Режим паузи = push-to-talk (UA→EN):** **тримаю** клавішу (пауза діє, лише поки тримаю) → мій мікрофон мутиться **для всіх у дзвінку, крім асистента** → кажу слово/фразу українською → асистент дуже швидко показує англійський переклад → читаю його вголос.
  - Мета: швидка підказка, коли забув слово чи фразу.
- Головна вимога: **мінімальна затримка**.

### 1в. Денний звіт для Upwork
- Денний звіт **потрібен** (а тижневий ні).
- Формат: **короткі повідомлення до 140 символів** (ліміт Upwork), окремо по кожній задачі або проєкту/замовнику.
- Час по задачах у кінці дня я розподіляю вручну й приблизно (див. нижче).

### 1г. Аналіз роботи в Claude Code за день
- Асистент читає, що я робив у Claude Code за день: **у якому проєкті і для якого замовника**, і на цій основі готує чернетку денного звіту.
- Звідки брати дані:
  - **Локальні сесії Claude Code**: історія лежить у `%USERPROFILE%\.claude\projects\<папка-проєкту>\*.jsonl`, по файлу на сесію. Там є робоча папка, час і повідомлення.
  - **Git** у тих самих репозиторіях: `git log` за день (коміти, гілки).
  - Хмарні сесії Claude Code **не враховуємо**, бо всі проєкти локальні.
- Зв'язок «папка/репозиторій → проєкт → замовник» налаштовую один раз у самому асистенті.
- LLM стискає зроблене за день у фрази до 140 символів, а я їх правлю й копіюю в Upwork.

### 1б. Швидкий таск із буфера обміну
- Копіюю текст із месенджера → натискаю хоткей → створюється таск із цим текстом → обираю **проект/замовника** → таск готовий.
- Отже потрібна сутність **«Проект / замовник»**, до якої прив'язуються задачі.

### Рішення
- **Програми для дзвінків:** переважно Teams і Zoom, іноді Google Meet і Slack (huddles).
- Приватність не критична, але **розпізнавання і переклад робимо локально** на RTX 3060 12 ГБ (Whisper + Opus-MT). Хмара (Azure Speech) лишається запасним варіантом із перемикачем.

### Додаткові опції (прийняті, крім позначених як відхилені)
- Налаштування прозорості вікна.
- Конспект мітингу після дзвінка + автоматичне додавання action items у задачі.
- Глосарій термінів/імен для точнішого перекладу.
- ~~Озвучка англійської фрази синтезованим голосом у дзвінок~~ — **відхилено** (користувач читає сам).
- Швидке додавання задачі текстом типу «завтра о 10 написати Олегу».
- Автоперенесення незроблених задач на наступний день.
- Нагадування.
- **Нагадування про мітинги з календаря**: обидва, Outlook і Google Calendar.
- ~~Таймер на задачу~~ — **відхилено**: задачі йдуть паралельно. Замість нього: **наприкінці дня у звіті вручну приблизно розподіляю час** по задачах.
- **Історія мітингів** (субтитри/переклади) із пошуком. Розрізняє лише «я» та «інші», без імен мовців.
- **Режим «не турбувати»**.
- Експорт звіту (буфер обміну / Markdown / Telegram / Slack).
- **Ранковий план дня**.
- ~~Тижневий звіт~~ — **відхилено** (окремі звіти не потрібні).

### На майбутнє / наступні фази
- Інтеграція з **Clockify** (облік часу).
- Контекстна підказка відповіді на мітингу.
- Персональний словник.
- Звіт для замовника.
- Автотаски з мітингу (див. прийняте «Конспект мітингу + action items»).

### Рішення 2026-11-25 (після оцінки плану)
- MVP ділимо на дві частини: **1a** (вікно, проєкти, задачі, швидкий таск, ранковий план, денний звіт) і **1b** (мітинги).
- Паузу робимо **одразу через драйвер віртуального мікрофона** (VB-Cable), натискання mute у програмах не розглядаємо.
- Субтитри: Whisper + Opus-MT en→uk, інші варіанти не потрібні.
- Пауза UA→EN: на етапі 0 порівнюємо Whisper large-v3 translate і turbo + Opus-MT uk→en (turbo сам не перекладає).
- Silero VAD і спільний екземпляр Whisper це технічна деталь, яку перевіряємо на етапі 0, а не окрема вимога.
- Розбір сесій Claude Code робимо окремим ізольованим модулем.
