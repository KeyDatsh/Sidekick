# Асистент для Windows: план (коротко)

Повний план зі схемами: https://claude.ai/artifact/258cu9Rh8vuJ6wLjAtAPcA
Макет інтерфейсу: https://claude.ai/artifact/8VexLzvpgi1qPKCT1UotTA
Вимоги та ідеї: [ideas.md](ideas.md)

## Стек
- Rust + Tauri 2 (WebView2), темна тема Windows 11, ефект Acrylic.
- Приховування від демонстрації екрана: `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`.
- Click-through у неактивному стані, хоткеї з налаштувань (`tauri-plugin-global-shortcut`).
- SQLite (`rusqlite`, FTS5 для пошуку).
- Звук дзвінка: WASAPI loopback. Режим паузи працює одразу через драйвер віртуального мікрофона (VB-Cable), без натискання mute у програмах для дзвінків.
- Розпізнавання і переклад працюють **локально на RTX 3060 12 ГБ**. Для субтитрів: Whisper (`whisper-rs`, CUDA) разом з Opus-MT en→uk (`ct2rs`). Для паузи UA→EN на етапі 0 порівнюємо два варіанти: Whisper large-v3 у режимі translate або large-v3-turbo для розпізнавання плюс Opus-MT uk→en (turbo сам перекладати не навчений). Azure Speech лишається запасним варіантом, його вмикає перемикач.
- Звіти: LLM API. Дані беруться із сесій Claude Code (`%USERPROFILE%\.claude\projects\*\*.jsonl`, їх розбирає окремий ізольований модуль) і `git log`.

## Етапи
0. Прототипи ризикових місць: прозоре вікно, яке не видно при демонстрації екрана, віртуальний мікрофон, замір затримки. Тут же перевіряємо технічні деталі: яку модель брати для паузи, Silero VAD і один спільний екземпляр Whisper.
1a. MVP: вікно, проєкти/замовники, задачі по днях, швидкий таск, ранковий план, денний звіт (записи до 140 символів).
1b. MVP: мітинги, тобто субтитри EN→UA і режим паузи UA→EN.
2. Аналіз сесій Claude Code і git для звіту, нагадування з календаря, режим «не турбувати», експорт звіту.
3. Історія мітингів із пошуком (розрізняє лише «я» та «інші», без імен), глосарій, конспект мітингу з action items, додавання задач звичайним текстом.
Далі: Clockify, контекстні підказки, персональний словник, звіт для замовника.

## Рішення
- Пауза працює, лише поки тримаєш клавішу.
- Календар: обидва, Outlook (Microsoft Graph) і Google Calendar.
- Розпізнавання працює локально на GPU (RTX 3060 12 ГБ), хмара лише запасний варіант.
- Хмарні сесії Claude Code не враховуємо, бо всі проєкти локальні.

Відкритих питань немає.
